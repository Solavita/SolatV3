# คู่มือใช้งาน SOLAT V3–V6

คู่มือนี้อธิบายเฉพาะฟังก์ชันที่มีอยู่จริงใน build ปัจจุบัน ตั้งแต่ Browser
Workspace (V3) ไปจนถึง Multimodal Fusion (V6)

## ก่อนเริ่ม

1. เปิด `SOLAT.exe` และสร้างหรือเลือกบทสนทนา เพราะทุกเหตุการณ์จะผูกกับบทสนทนานั้น
2. ปุ่ม V3–V5 อยู่แถวเดียวกับช่องพิมพ์:
   - รูปแว่นขยาย — Browser Workspace
   - รูปมือ `✋` — Hand Tracking
   - รูปคลิปหนีบ — แนบรูปจากเครื่องเพื่อใช้เป็น SpatialAsset
3. เปิดคู่มือย่อในแอปได้ด้วย `Ctrl+G` แล้วเลือก **V3–V6 tutorial**

> ข้อมูลการเลือก รูป และความจำอ้างอิงของแต่ละบทสนทนาไม่ถูกแชร์ข้ามบทสนทนา

## V3 — Browser Workspace

### 1. เปิดพื้นที่เว็บ

1. กดปุ่มรูปแว่นขยายข้างช่องพิมพ์
2. SOLAT จะเปิดหน้าต่าง **SOLAT Browser Workspace** และเริ่มที่ Pinterest
3. พิมพ์ URL แบบ `https://...` หรือคำค้นในช่องด้านบน แล้วกด `Enter`

ปุ่ม `Back`, `Forward`, `Reload` และ `Close` ใช้เหมือนเบราว์เซอร์ทั่วไป

### การล็อกอินและปุ่ม Chrome

- ฟอร์มอีเมล/รหัสผ่าน/OTP ของเว็บไซต์ทั่วไปกรอกเองได้เมื่ออยู่ใน **Take control**
- หน้า Login, OAuth, challenge, Password และ OTP ทั้งหน้าจะแสดง
  **PRIVATE INPUT · SOLAT BLIND**; ระหว่างนั้น Agent สังเกต จับภาพ หรือสั่งหน้าเว็บไม่ได้
- Google ไม่อนุญาต OAuth ใน embedded browser: เมื่อเว็บไปที่ Google ระบบจะเปิด
  หน้าเว็บต้นทางใน Chrome ให้กด **Continue with Google** อีกครั้งใน Chrome
- ปุ่ม **Chrome** ใช้เปิดหน้าปัจจุบันใน Chrome ด้วยตัวเองได้ การล็อกอินนั้นจะอยู่ใน
  Chrome และไม่ถูกย้ายกลับด้วย cookie/token
- ถ้าต้องการให้ session อยู่ใน Browser Workspace ต้องใช้วิธีล็อกอินที่เว็บไซต์ยอมรับ
  ภายในหน้านั้น เช่นอีเมล/รหัสผ่านของเว็บไซต์เอง; ความสำเร็จขึ้นกับนโยบายของเว็บ

### เอารูปจาก Chrome กลับเข้า Blue Workspace

1. ล็อกอินและเปิดหน้าปกติใน Chrome ให้พ้นหน้า Login/Password/OTP ก่อน
2. คลิกขวารูปแล้วเลือก **Copy image**
3. กลับ SOLAT แล้วกด `Ctrl+V` ภาพจะเข้า SpatialAsset V4 และกลายเป็น ghost ใน Blue
4. เลื่อนภาพแล้วปล่อยหรือคลิกเพื่อวาง; provenance URL จะเก็บเฉพาะเมื่อ Chrome
   ส่ง URL สาธารณะมาพร้อมภาพ
5. สามารถลากภาพจาก Chrome มาวางที่ composer ได้โดยตรงเมื่อ Chrome ส่ง image bytes;
   หาก Chrome ส่งมาแค่ลิงก์ SOLAT จะไม่ดาวน์โหลดเองและจะแนะนำ Copy image แทน

เส้นทางนี้ไม่อ่าน cookie, token, password manager หรือ DOM ของ Chrome และไม่รับ SVG,
URL local/private หรือภาพเกิน 8 MB

### 2. สลับระหว่างคนกับ SOLAT

- กด **Take control** เมื่อต้องการคลิก เลื่อน หรือพิมพ์บนหน้าเว็บด้วยตัวเอง
- กด **Return control** เมื่อต้องการคืนการควบคุมให้ Agent
- ระหว่าง Take control อยู่ SOLAT จะไม่สั่งหน้าเว็บแทนคุณ

### 3. สิ่งที่ควรเห็น

- แถบสถานะจะแสดงสถานะของพื้นผิวเว็บ
- หน้าต่างเว็บเปิด/ปิดแยกจากหน้าหลัก จึงไม่บังคับแบ่งจอแบบ 50/50
- หน้าเว็บยังอยู่เหมือนเดิมเมื่อเลือกรูปไปใช้ใน V4

### ข้อจำกัดด้านความปลอดภัย

- รับเฉพาะเว็บ HTTP/HTTPS สาธารณะ และปิดการเข้าถึง local/private network
- popup และ download เปิดเฉพาะตอนคน Take control; permission จากเว็บปิดโดยค่าเริ่มต้น
- CAPTCHA, passkey/password manager และความเข้ากันได้กับทุกเว็บไซต์ยังต้องทดสอบด้วยคน

## V4 — SpatialAsset และการย้ายรูปข้ามพื้นผิว

### 1. เอารูปจากเว็บเข้า Blue Workspace

1. เปิด Browser Workspace
2. กด `Alt` ค้างแล้วคลิกรูปหรือวัตถุภาพที่มองเห็นบนหน้าเว็บหนึ่งครั้ง
3. กด **Use image** บนแถบด้านบน
4. เมื่อสำเร็จ สถานะจะเปลี่ยนเป็น **IMAGE HELD**
5. กด **Close** เพื่อกลับ Blue Workspace รูปจะติดตามตัวชี้เป็นภาพโปร่งหรือ ghost
6. เลื่อนเมาส์ไปตำแหน่งที่ต้องการ แล้วปล่อยเมาส์หรือคลิกเพื่อวาง

เมื่อวางสำเร็จ SOLAT จะแสดงข้อความว่าใช้คำว่า **“รูปที่เพิ่งแปะ”** อ้างถึงรูปนั้นได้

### 2. เอารูปจากเครื่องมาใช้

1. กดปุ่มคลิปหนีบและเลือกรูป
2. เมื่อ thumbnail ปรากฏเหนือช่องพิมพ์ ให้กดค้างบน thumbnail
3. เลื่อนรูปไปตำแหน่งที่ต้องการใน Blue Workspace
4. ปล่อยเพื่อวาง

### 3. ยกเลิกการถือรูป

กด `Esc` ขณะมี ghost อยู่ รูปต้นฉบับจะไม่ถูกลบหรือแก้ไข

### 4. ความจำของ SpatialAsset

ระบบเก็บข้อมูลเชิงโครงสร้างของสิ่งที่เพิ่งเลือก ลาก และวาง รวมถึงแหล่งที่มาของรูป
เพื่อให้พูดหรือพิมพ์ต่อได้ เช่น:

- `ขยายรูปที่เพิ่งแปะ`
- `ใช้อันนี้เป็น reference`
- `รูปก่อนหน้านี้ไม่เอา`

การวางเข้า Blue Workspace ใช้งานได้แล้ว แต่การให้เว็บไซต์ภายนอกรับรูปโดยตรงแทน
native drag-and-drop ยังไม่ถือว่าผ่านการทดสอบจริงทุกเว็บ

## V5 — Hand Tracking

### 1. เปิดกล้อง

1. จัดให้มือและใบหน้าไม่บังกัน มีแสงพอ และเห็นมือครบทั้งฝ่ามือ
2. กดปุ่ม `✋` ข้างช่องพิมพ์
3. อนุญาต Camera เมื่อ Windows/Electron ถาม
4. เมื่อปุ่มอยู่ในสถานะกดค้าง ระบบกำลังติดตามมือ
5. กด `✋` อีกครั้งเพื่อหยุดกล้อง

การเปลี่ยนบทสนทนาจะหยุด Hand Tracking อัตโนมัติ

### 2. ท่าทางมือ

| ท่าทาง | วิธีทำ | การทำงาน |
| --- | --- | --- |
| Point | ชูนิ้วชี้และพับนิ้วอื่นอย่างน้อยสองนิ้ว | ชี้ตำแหน่งหรือเริ่มเลือก thumbnail ใต้ปลายนิ้ว |
| Pinch | แตะปลายนิ้วโป้งกับปลายนิ้วชี้ | จับ SpatialAsset ใต้ตำแหน่ง pinch |
| Grab | กำนิ้วอย่างน้อยสามนิ้ว | จับรูป; เมื่อเคลื่อนเกินระยะเล็กน้อยจะกลายเป็น drag |
| Drag | ค้าง grab แล้วเลื่อนมือ | ย้าย ghost ตามมือ |
| Release | คลายท่าจับหรือเอามือออกจากเฟรมช่วงสั้น ๆ | วางรูปที่กำลังถือ |
| Scale | ให้ระบบเห็นมือสองข้าง แล้วขยับระยะห่างระหว่างฝ่ามือ | ย่อหรือขยายรูปที่กำลังถือ |
| Rotate | ให้ระบบเห็นมือสองข้าง แล้วหมุนแนวระหว่างฝ่ามือ | หมุนรูปที่กำลังถือ |

ท่าทางต้องค้างอย่างน้อยประมาณสองเฟรมเพื่อลดอาการสั่น และตำแหน่งถูกทำ smoothing
อัตโนมัติ

### 3. วิธีทดลองที่สั้นที่สุด

1. แนบรูปให้เกิด thumbnail
2. เปิด Hand Tracking
3. เลื่อน pinch หรือปลายนิ้วชี้ให้อยู่บน thumbnail แล้วค้างสั้น ๆ
4. เลื่อนมือเพื่อย้ายรูป
5. คลายมือเพื่อวาง

### ความเป็นส่วนตัว

MediaPipe ประมวลผลภาพกล้องใน renderer ของเครื่อง เฉพาะ landmark มือแบบตัวเลข
สูงสุดสองมือถูกส่งเข้า core; raw video และ raw camera frame ไม่ถูกบันทึก

คุณภาพจริงขึ้นกับกล้อง แสง ระยะมือ DPI และสิ่งบังมือ จึงยังเป็นส่วนที่ต้องทดสอบด้วยคน

## V6 — Multimodal Fusion, ความจำ และ Undo

V6 ทำงานอัตโนมัติ ไม่ต้องเปิดโหมดแยก ระบบเรียงเหตุการณ์จากเสียง การชี้ มือ หน้าจอ
และ SpatialAsset ตามเวลา แล้วใช้เหตุการณ์ล่าสุดแก้คำอ้างอิง

### 1. อ้างถึงสิ่งที่เพิ่งทำ

หลังเลือก ชี้ หรือลากวัตถุ ให้พูดหรือพิมพ์ภายในประมาณสองนาที เช่น:

- `อันนี้คืออะไร`
- `แก้ตรงนี้ให้เข้มขึ้น`
- `ใช้รูปที่เพิ่งแปะเป็น reference`
- `หน้าจอนี้มีอะไรสำคัญ`
- `เอาอันก่อน ไม่ใช่อันนี้`

ถ้าระบบหาหลักฐานอ้างอิงไม่ได้ ระบบควรถามให้ชัดแทนการเดา

### 2. Undo ความจำล่าสุด

1. กด `Ctrl+G`
2. พิมพ์ `Undo last interaction reference`
3. กด `Enter`

คำสั่งนี้ลบ **เหตุการณ์อ้างอิงล่าสุด** ออกจาก interaction memory ไม่ได้ลบข้อความแชต
หรือไฟล์ต้นฉบับ

### 3. กู้สถานะหลังเปิดใหม่

ความจำเชิงเหตุการณ์ถูกบันทึกแบบแยก owner/session และมี checksum ตรวจความเสียหาย
เมื่อเปิด SOLAT ใหม่ ระบบพยายามกู้เหตุการณ์เดิม หาก snapshot เสียจะลดระดับเป็นการขอ
คำชี้แจงแทนการใช้ข้อมูลที่เชื่อถือไม่ได้

### 4. สิ่งที่ระบบไม่เก็บในความจำนี้

- raw เสียงจากไมโครโฟน
- raw ภาพหรือวิดีโอกล้อง
- screenshot bytes
- API key หรือ credential

## แก้ปัญหาเบื้องต้น

| อาการ | วิธีตรวจ |
| --- | --- |
| Browser Workspace เปิดไม่ได้ | ต้องมีบทสนทนาที่กำลังเลือกอยู่ และ URL ต้องเป็น public HTTPS |
| Use image ขึ้น `ALT-CLICK IMAGE FIRST` | กด `Alt` ค้างแล้วคลิกรูปใหม่; อย่าเปลี่ยนหน้าก่อนกด Use image |
| รูปไม่ตามเมาส์หลังเลือกจากเว็บ | ปิด Browser Workspace ก่อนเพื่อกลับ Blue Workspace |
| Hand Tracking เปิดไม่ได้ | ตรวจ Camera permission ของ Windows, ปิดแอปอื่นที่ครองกล้อง แล้วกด `✋` ใหม่ |
| ท่าทางติด ๆ ดับ ๆ | เพิ่มแสง ให้เห็นมือครบ และค้างท่าประมาณสองเฟรมขึ้นไป |
| “อันนี้” ถูกถามกลับ | ทำ interaction ใหม่แล้วส่งข้อความภายในสองนาที หรือใช้คำที่เจาะจงกว่า |
| ต้องการล้าง reference ล่าสุด | `Ctrl+G` → `Undo last interaction reference` |

## สถานะการยืนยัน

ฟังก์ชันและ regression อัตโนมัติของ V3–V6 ผ่านแล้ว แต่การยอมรับเชิงกายภาพ เช่น
คุณภาพท่าทางกับกล้องจริง เว็บที่ต้องล็อกอิน การวางลงแอปภายนอก และการใช้งานต่อเนื่อง
เป็นเวลานานยังเป็น `MANUAL REVIEW REQUIRED`
